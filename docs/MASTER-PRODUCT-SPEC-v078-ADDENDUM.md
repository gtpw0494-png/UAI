## Governing invariant

AI/model components may propose, reason, plan, learn, simulate, adapt and recover. Authorization remains external to model cognition and is governed by authenticated identity, explicit permission, capability scope, policy, security, approval where required, independent verification, recovery and audit.

## v0.78 Forge Cognitive Fabric

v0.78 adds ForgeNGN, Capability Confidence Router, Evidence-Gain Scout and Evidence Portfolio Optimizer as an additive experimental layer. ForgeNGN uses candidate compute gears, causal attention, temporal mixing, pulse gating and clutch routing. Neural confidence is advisory. It cannot grant capability, verify evidence, approve an action, bypass policy, mutate live production topology or promote a model.

`OneChat → ForgeLM/ForgeNGN candidate → evidence truth → confidence/evidence planning → Decision Proof → Policy → Capability Firewall → approval/scoped token → execution → independent verification`.

Growth path:
`metrics → GrowthPlanner → ForgeDream → ForgeCanary → held-out evaluation → ForgeCurriculum → governed promotion → signed artifact`.

Status remains `IMPLEMENTED_UNVERIFIED_REPO` until authoritative CI succeeds on the exact integration state. A trained/evaluated/promoted ForgeNGN artifact is separately required before runtime capability claims.

## Artifact reconciliation rule

Git contains reproducible source, tests, safe configuration, schemas, curated specifications and manifests. Credentials, private conversations, personal data, mutable state/databases, model run directories, dependency trees and large duplicate archives are not blindly merged. External/private artifacts are represented by governed storage plus hashes/provenance. Missing artifacts are recorded as missing rather than invented.

Historical WitForge specifications/releases, ForgeLM checkpoints, 4H3 archives, prompts/responses and produced files remain provenance inputs. Their functionality is not projected onto current main unless current implementation and verification evidence exists.
